## ✨ Características y Animaciones Incluidas
- **Marca de agua sutil del Logo**: El logotipo de la 'A' con alas está integrado en el fondo con baja opacidad (sin robar protagonismo) y con movimiento suave de respiración.
- **Micro-interacciones al dar clic**:
  - Explosión de confeti suave con los colores de la marca.
  - Chime sonoro sutil sintetizado por Web Audio API.
  - Efecto de elevación 3D y brillo (*shimmer*).
- **Cinta Ticker Continua (Marquee)**: Texto continuo animado con información de telas Rib Premium, envíos nacionales y confección.
- **Botón Flotante de WhatsApp**: Acceso rápido en móviles con mensaje interactivo.
- **Modal para Compartir y Código QR**: Permite escanear con la cámara del móvil o copiar el enlace directo al portapapeles.
- **Sección Desplegable de Beneficios**: Resumen de atributos de la tela Rib Premium, tallas y ventajas de venta mayorista.

## 🚀 Cómo ejecutar en desarrollo

```bash
npm run dev
```

Abre en tu navegador: [http://localhost:3000](http://localhost:3000)

## 📦 Cómo compilar para producción

```bash
npm run build
npm run start
```

## 🌐 Despliegue en 1 Clic (Vercel)
Este proyecto es 100% compatible con Vercel. Puedes subirlo a tu repositorio de GitHub e importarlo en [vercel.com](https://vercel.com) para tener tu linktree online gratis y con dominio propio o subdominio `.vercel.app`.
